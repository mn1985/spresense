# ステッピングモータ連動カメラシステム

## 概要

28BYJ-48 ステッピングモータを使用して、±180度の範囲で回転しながら自動的に撮影を行うシステムです。

## 仕様

### ステッピングモータ: 28BYJ-48
- **1回転のステップ数**: 4096ステップ
  - モーター本体: 64ステップ/回転
  - 内蔵ギア比: 1/64
  - 実際: 64 × 64 = 4096ステップ

### 撮影設定
- **撮影間隔**: 256ステップごと
- **1回転の分割数**: 4096 ÷ 256 = 16分割
- **回転範囲**: ±180度 (±2048ステップ)
- **撮影枚数**: 16枚

### 動作シーケンス

1. **Phase 1**: 0° → +180° (8枚撮影)
   - 0°で撮影
   - 256ステップ回転
   - 撮影を繰り返し
   - +180°まで

2. **Phase 2**: +180° → -180° (8枚撮影)
   - 256ステップ逆回転
   - 撮影
   - 繰り返し
   - -180°まで

3. **Phase 3**: -180° → 0° (撮影なし)
   - ホームポジションに戻る
   - ケーブルのよれを防止

## GPIO接続

Spresenseメインボードのピン配置:

| モータピン | 信号名 (Main Board) | 内部ピン番号 | 備考 |
|-----------|------------------|-------------|-----|
| IN1       | I2S0_BCK         | PIN_I2S0_BCK (93) | 1.8V Level |
| IN2       | I2S0_LRCK        | PIN_I2S0_LRCK (94) | 1.8V Level |
| IN3       | I2S0_DATA_IN     | PIN_I2S0_DATA_IN (95) | 1.8V Level |
| IN4       | I2S0_DATA_OUT    | PIN_I2S0_DATA_OUT (96) | 1.8V Level |

**注意**: これらのピンはI2S0インターフェース用のピンですが、GPIOとしても使用できます。I2S0を使用する場合は、別のピンを選択してください。

### 接続方法

```
28BYJ-48 + ULN2003ドライバ
┌─────────────┐
│  ULN2003    │
│  IN1 ───────┼─── Spresense Main I2S0_BCK (1.8V)
│  IN2 ───────┼─── Spresense Main I2S0_LRCK (1.8V)
│  IN3 ───────┼─── Spresense Main I2S0_DATA_IN (1.8V)
│  IN4 ───────┼─── Spresense Main I2S0_DATA_OUT (1.8V)
│  VCC ───────┼─── 5V (外部電源推奨)
│  GND ───────┼─── GND
└─────────────┘
```

**重要**: SpresenseメインボードのIO電圧は **1.8V** です。
ULN2003等の5V駆動ドライバを直接制御できない場合があります（信号電圧不足）。
その場合は、適切なレベルシフタ（1.8V → 3.3V/5V）を使用してください。

**注意**: モータは5V電源が必要です。Spresenseから直接給電すると電流不足になる可能性があるため、外部5V電源の使用を推奨します。

## コマンド

### Spresense側
プログラム起動後、以下のコマンドが使用可能:

- `s` - 自動回転・撮影シーケンス開始
- `c` - 単発撮影（モータ動作なし）
- `q` - 終了

### PC側 (recv_image.py)

```bash
python3 recv_image.py -p /dev/ttyUSB0 -o captured_image.jpg
```

起動後、以下のコマンドが使用可能:

- `s` - 自動シーケンス開始（16枚受信）
- `c` - 単発撮影
- `q` - 終了

## タイミング設定

現在の設定:
- **ステップ間隔**: 1ms (STEP_DELAY_US = 1000)
- **撮影間待機**: 100ms
- **256ステップ移動時間**: 約256ms

必要に応じて `usb_cam_serial_main.c` の以下の定義を変更:

```c
#define STEP_DELAY_US     1000    /* ステップ間隔 (マイクロ秒) */
```

値を大きくすると:
- モータの動作が遅くなる
- トルクが安定する
- 振動が減る

値を小さくすると:
- 動作が速くなる
- 脱調のリスクが増える

## トラブルシューティング

### モータが動かない
- GPIO接続を確認
- 外部5V電源が供給されているか確認
- ULN2003ドライバボードのLEDが点灯するか確認

### モータが脱調する（ステップを飛ばす）
- `STEP_DELAY_US` を大きくする（例: 2000）
- 電源電圧を確認（5V安定供給）
- モータの負荷を減らす

### 画像が受信できない
- シリアルポートが正しいか確認
- ボーレートが一致しているか確認（115200）
- 両方のプログラムが同時に起動しているか確認

## カスタマイズ

### 撮影間隔を変更

`usb_cam_serial_main.c` の以下を変更:

```c
#define STEPS_PER_CAPTURE 256     /* この値を変更 */
```

例:
- 128ステップ → 32分割（32枚撮影）
- 512ステップ → 8分割（8枚撮影）

**注意**: PC側スクリプトの `num_images` も変更が必要です。

### 回転範囲を変更

完全360度回転にする場合:

```c
#define MAX_ANGLE_STEPS   2048    /* 4096に変更で360度 */
```

ただし、ケーブルのよれに注意してください。
